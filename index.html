جۆرەکانی داتا لە Java

سمینار لەسەر Data Types لە Object-Oriented Programming: هەر جۆرێک چییە، چەند بیر داگیر دەکات، و کەی بەکاردێت.

Data Type چییە؟

Data Type دیاری دەکات گۆڕاوەکە (Variable) چ جۆرە داتایەک هەڵدەگرێت، چەند بیر (Memory) داگیر دەکات، و چ کارێک لەسەری دەکرێت. Java زمانێکی Strongly Typedـە: پێویستە جۆری هەموو گۆڕاوێک پێش بەکارهێنان دیاری بکرێت.

int age = 20;

Primitive

٨ جۆری سەرەتایی، بەهاکە ڕاستەوخۆ هەڵدەگرن.

Reference

ئاماژە بۆ Object لە Heap هەڵدەگرن: String, Array, Class, Interface, Enum...

Primitive Data Types

درێژی هێڵە سەوزەکە قەبارەی بیرە (بایت).

جۆرقەبارەبۆچی بەکاردێتنموونە
byte١ بایت
ژمارەی تەواوی بچووک (-١٢٨ تا ١٢٧)؛ بۆ پاشەکەوتکردنی بیر و کار لەگەڵ فایل/Networkbyte b = 100;
short٢ بایت
ژمارەی تەواو، لە byte گەورەترshort s = 5000;
int٤ بایت
باوترین جۆر بۆ ژمارەی تەواو (تەمەن، ژماردن)int age = 20;
long٨ بایت
ژمارەی تەواوی زۆر گەورە (دراو، کات، population)long p = 8000000000L;
float٤ بایت
ژمارەی دەهەمی (وردییەکی کەمتر)float f = 3.14f;
double٨ بایت
ژمارەی دەهەمی بە وردی زیاتر (حیساباتی زانستی)double d = 3.14159;
char٢ بایت
یەک پیت یان هێماchar c = 'A';
boolean١ بیت (بە تیۆری)
تەنها true یان false، بۆ مەرج و بڕیارboolean ok = true;

تایبەتمەندییەکان

  • بەهاکە ڕاستەوخۆ لە Stack Memory هەڵدەگرن؛ خێرا و سادەن.
  • Object نین و Method یان Property نییان.
  • وەک Field لە Class Default Value یان هەیە: int = 0، double = 0.0، boolean = false.

Non-Primitive (Reference) Types

ئاماژە (Reference) بۆ Object لە Heap Memory هەڵدەگرن، نەک خودی بەهاکە.

String

بۆ دەق. Object-ە و Immutable-ە (ناگۆڕدرێت).

String name = "Ahmed";
System.out.println(name.length());

Array

کۆمەڵەیەک داتا لە هەمان جۆر لە یەک گۆڕاودا.

int[] numbers = {10, 20, 30};

Class

قاڵبی دروستکردنی Object، گرنگترین بنەمای OOP.

class Student { String name; int age; }
Student s = new Student();

Interface

گرێبەستێک کە دیاری دەکات Class چ Method-ێکی دەبێت؛ بۆ Abstraction و Polymorphism.

Enum

کۆمەڵەیەک بەهای نەگۆڕی ناودار، وەک ڕۆژەکانی هەفتە.

enum Day { SATURDAY, SUNDAY, MONDAY }

Collections

ArrayList، HashMap، HashSet بۆ بەڕێوەبردنی کۆمەڵە داتای گۆڕاو لە قەبارە.

Wrapper Classes

هەر جۆرێکی Primitive Class-ێکی هاوتای هەیە:

PrimitiveWrapper
intInteger
doubleDouble
charCharacter
booleanBoolean
longLong

بۆچی بەکاردێن؟ بۆ بەکارهێنان لەناو Collections (ArrayList<Integer>)، بۆ گۆڕین نێوان جۆرەکان (Integer.parseInt("123"))، و بۆ بەهای null.

Integer x = 5;   // Autoboxing
int y = x;       // Unboxing

Type Casting

Widening (خۆکار)

بچووک ← گەورە

int a = 10;
double b = a;   // 10.0

Narrowing (دەستی)

گەورە ← بچووک، لەوانەیە بەشێک لە داتا ون بێت.

double x = 9.7;
int y = (int) x;   // 9

کام جۆر هەڵبژێرم؟

جۆرێکی داتا هەڵبژێرە و ڕێنماییەکە ببینە:

یەکێک لە دوگمەکان دابگرە.

نموونەی تەواو

public class Student {
    String name;        // String
    int age;            // int
    double gpa;         // double
    boolean isActive;   // boolean
    char grade;         // char

    public static void main(String[] args) {
        Student s = new Student();
        s.name = "Sara";
        s.age = 21;
        s.gpa = 3.8;
        s.isActive = true;
        s.grade = 'A';
        System.out.println(s.name + " - " + s.gpa);
    }
}

کورتەی سمینار

  • Java هەشت جۆری Primitive و چەندین جۆری Reference هەیە.
  • هەڵبژاردنی جۆری دروست کارایی و بیر باشتر دەکات.
  • لە OOP دا Class، Interface و Enum جۆری تایبەتی خۆمانن.
  • Wrapper Classes پردی نێوان Primitive و Object-ن.
